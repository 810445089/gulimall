## 1、let 声明变量

```
let：
1、局部作用域，作用域只是当前代码块
2、同名变量只能声明1次
3、不存在变量提升

var：
1、全局作用域，例如在{}代码块内部声明，代码块外部仍然可以被使用
2、同名变量可以被多次声明
3、存在变量提升【在声明之前被调用，不会报空指针is not defined，而是报错undefined】
	【undefined表示变量已声明，但是赋值为undefined了，is not defined是空指针不存在变量】
```

### 2）reduce() 方法

```javascript
功能介绍：reduce()为数组中的每个元素依次执行回调函数，返回结果作为下一次执行回调函数的参数
reduce(callBack(previousValue, currentValue), initiaValue)
【要求callBack函数带返回值】
   
    /** arr.reduce(callBack(previousValue, currentValue), initiaValue)
                1、previousValue(上一次调用回调返回的值，或者是提供的初始值(initialValue))
                2、currentValue(数组中当前被处理的元素)
                3、callBack函数执行的结果值将作为下一次调用的callBack的previousValue
                4、最后一次调用callback的返回值将作为reduce方法的返回值 */

        console.log("当前数组：" + arr);

        let result = arr.reduce((previousValue, currentValue) => {
            console.log("上一次处理后：" + previousValue);
            console.log("当前正在处理：" + currentValue);
            return previousValue + currentValue;
        }, 100);

        console.log("最后结果：" + result)

```

## 8、Promise 对象

前言：
在JavaScript的世界中，**所有代码都是单线程执行的**。由于这个“缺陷”，导致JavaScript的所有**网络操作**，浏览器事件，都必须是**异步执行**。异步执行可以用回调函数实现。**一旦有一连串的ajax请求a,b,..后面的请求依赖前面的请求结果，就需要层层嵌套**。这种**缩进和层层嵌套**的方式，非常**容易造成上下文代码混乱**，我们不得不非常小心翼翼处理内层函数与外层函数的数据，一旦内层函数使用了上层函数的变量，这种混乱程度就会加剧..总之，这种"层叠.上下文的层层嵌套方式，着实增加了神经的紧张程度。

```javascript
Promise功能介绍：
	1、解决代码缩进造成的代码混乱，对层层调用操作进行编排
    2、Promise对象的构造函数是异步执行的，不会阻塞主函数的执行
    3、只有当resolve被调用时，then方法才会被调用；当调用reject时，then方法不会被调用
    
    
        new Promise((resolve, reject) => {
            // 异步操作1
            $.ajax({
                url: "url1",
                success: function (data) {
                    resolve(data);
                },
                error: function (err) {
                    reject(err);
                }
            });
        }).then((obj) => {
            return new Promise((resolve, reject) => {
                // 异步操作2
            	$.ajax({
                    url: "url2",
                    success: function (data) {
                        resolve(data);
                    },
                    error: function (err) {
                        reject(err);
                    }
                });    
           	});
        }).then((obj) => {
                // 异步操作3
            	$.ajax({
                    url: "url3",
                    success: function (data) {
                        xxx
                    },
                    error: function (err) {
                        xxx
                    }
                });    
        });
```

```html

    <li>西游记； 价格：{{xyjPrice}}，数量：<input type="number" v-model="xyjNum"> </li>
```

## 11、总结+梳理【重要，看这里】

总结：.js（纯js代码，定义实例、变量）、.vue（单文件组件）、.html（渲染模板）【其中.js文件与.vue文件互相依赖进行渲染（template被作为模板渲染），html文件可以被作为模板进行渲染也可以在内部写js语句】

```js
解析router.js内部：

3、new Router实例并export导出
4、在routes属性内部指定一个数组
5、数组元素三个属性
	1）path：路由地址【当访问/hello时，App.vue组件的template中的<router-view/>就会渲染Hello组件】
    2）name：组件名
    3）component：组件

import Hello from '@/components/Hello'

    {
      path: '/',
      name: 'HelloWorld',
      component: HelloWorld
    },{
      path: '/hello',
      name: 'Hello',
      component: Hello
    }
  ]
})
```

```properties
区分.js文件、.html文件、.vue文件
.js文件：
1、js多用于绑定vue实例与div的绑定关系（用el:'#app'）
2、js文件可以import和export变量、函数、实例（vue、component、router）
3、js文件其实就是<script>标签内部代码单独抽离出来了
4、vue实例可以选择html作为模板渲染，也可以使用template属性指定的组件作为模板渲染

.html文件
1、多用作模板，模板与vue实例结合才能完成渲染。
2、内部可以指定<script>标签，内部代码跟.js文件的一样

.vue文件
1、一个单文件组件，一个vue实例，并在<script>以export default{name:App}的形式向外提供组件实例
1、包含template、script、style，是一个完整组件
```
